The Fixed Point
Lawvere's theorem — and the single purchase of power and limit. A system rich
enough to name itself finds, in the mirror, a point equal to its own image; that one
point is the engine of everything it can compute and the source of everything it
cannot complete.

LAWVERE · 1969
In a cartesian closed category, if there is a point-surjective map φ : A →
Bᴬ, then every endomorphism α : B → B has a fixed point — a point s
with α(s) = s.
THE PROOF, IN FIVE LINES
1 Fix α : B → B. Form g = α∘ev∘⟨φ,id⟩, so g(a) = α(φ(a)(a)).
2 Curry g to a point ⌜g⌝ : 1 → Bᴬ.
3 φ is point-surjective, so some a names g: φ(a) = g.
4 Set s = φ(a)(a).
5 s = φ(a)(a) = g(a) = α(φ(a)(a)) = α(s). ∎

If a twist on the answers has no fixed point of its own, the construction demands
an object that cannot exist — so the self-naming φ cannot exist. The wall every
formal system meets.

Where the answers admit a fixed point — a reflexive object, naming as application
— the construction hands one back, uniformly. The engine of all computation.
the Y-combinator · Kleene's recursion theorem · quines · the diagonal lemma
Power and limit are not opposites. They
are the two things you cannot have apart.
